# 通用网格拆件与补洞：几何约束与实现边界

本文件指导选择方法，不承诺从任意模型自动识别完整语义部件，也不承诺任意洞口一次补好或达到严格 G2 连续。先记录观察、推断和未知项，再选择最小可验证操作。保留原文件，以新版本交付；拓扑闭合、几何无交叉和表面好看是三个不同的验收项目。

## 已附带的标准库工具

`scripts/mesh_geometry.py` 不依赖 Blender、NumPy、SciPy 或操作系统特定库，提供两个可导入函数。它们不修改输入，不自行读写文件，不下载依赖，也不调用旧项目脚本。

- `partition_triangles(vertices, triangles, labels, *, part_ids=None, relative_tolerance=1e-12, absolute_tolerance=0.0)`：每张输入三角面只归属一个显式标签；按已有面边拆件，复制原坐标和绕序，返回每件的 `source_vertex_indices` 与 `source_face_indices`。`part_ids` 可指定完整清单和次序；未知标签、漏标、空部件和重复清单项会报错。标签为非负整数或非空字符串。部件可能开口或包含多个连通块，需要后续检查。此函数不在原三角面内部插入切线，不平滑接缝，不生成封口。
- `make_complementary_patch(vertices, triangles, boundary_loop, *, relative_tolerance=1e-12, absolute_tolerance=0.0)`：输入一个已经构造好的三角补面，以及沿补面有向边界排列的顶点索引。边界末尾不要重复起点。验证非退化、单连通面组、内边绕序、边界完全匹配、顶点面扇连通和拓扑圆盘条件后，返回 `forward` 与 `reverse` 两份补面。两份使用完全相同的坐标与连接关系，第二份反绕序，并提供一一对应索引。函数不产生凸起、不将补面焊接到原件，也不做碰撞或打印配合检查。

两函数只接受三角面与有限三维坐标，拒绝重复索引面、重复三角面和尺度容差下的退化面。输入中不同顶点 ID 即使同坐标也不合并。输出来源索引只指本次输入，跨多个阶段需要调用方继续组合来源映射。UV、材质、颜色、骨骼权重和逐角法线不包含在返回值中；调用方必须通过来源映射保留它们。

最小调用示例（使 `scripts` 目录位于 Python 模块搜索路径）：

```python
from mesh_geometry import partition_triangles, make_complementary_patch

v = [[0, 0, 0], [2, 0, 0], [2, 2, 0], [0, 2, 0], [1, 1, 0.6]]
t = [[0, 1, 4], [1, 2, 4], [2, 3, 4], [3, 0, 4]]
parts = partition_triangles(v, t, ["a", "b", "b", "a"], part_ids=["a", "b"])
pair = make_complementary_patch(v, t, [0, 1, 2, 3])
assert pair["forward"]["vertices"] == pair["reverse"]["vertices"]
assert not pair["checks"]["self_intersection_tested"]
```

从本技能目录运行小型测试：

```text
python -m unittest discover -s tests -p test_mesh_geometry.py -v
```

这些测试验证局部函数契约，不代表真实模型全流程验收，也不代表已在所有 Windows/macOS、Python 或 Blender 版本执行过。

## 完整清单先于切割与补洞

先把已有用户指示和可读到的源对象整理为任务清单；确实缺失的语义信息再询问。不要因为建立清单额外引入例行批准流程。

清单至少应包含：

- 源文件哈希、对象 ID、选择的是基础网格还是修改器求值结果、坐标变换、单位、朝向、是否保留原始材质与法线。正 X/负 X 不自动等同人物左/右。
- 期望全部部件的稳定 ID、名称、源面归属规则、必须保留的小片/窄桥、预期连通块、开口保留或闭合要求。未知片必须显式记为待判定；不能用“其余删除”消除不确定性。
- 所有接口的配对关系、共同接缝 ID、边界方向、凸/凹朝向、是否为独立封口或共用配合面，以及零间隙或具体间隙需求。
- 原面可移动的测地带宽、最大允许位移、可重分配的原面区域、不可改动区域，以及需要保留的原有开口或接触。
- 每件与全装配的验收条件、实际交付格式；补片、修改过的原面和未动原面的来源掩码。

冻结带版本号的清单和输入哈希之后再做全量切割。语义变更应使相关切缝、补面、验收与过程图缓存失效，不能只换文件名沿用旧报告。清单变化只重做受影响接口；已确认无关部件保留。

## 在原表面上预切并共享边界

降低返修次数的关键是先把切线做好，再为稳定边界建面。

1. 首先分析原网格：面邻接、连通块、裸边、分叉、独立顶点面扇、重复面、微小片和薄层。依赖网格邻接与测地距离选择区域，避免欧氏近邻误连相邻头发层、衣褶或对侧表面。
2. 若目标切线穿过原面，使用已确定的实际三角化作为权威表面。在三角形重心坐标内剪裁，按原无向边缓存交点；相邻面必须引用同一交点 ID。将交点传递给切线另一侧及锁定面，防止 T 形接缝。锁定面的细分可保持面积归属，不等同把它分给别的部件。
3. 多部件交会处宜在同一个分类场里一次分区，统一处理三类交点。逐件分别平滑、分别重算切线容易形成重叠、裂缝或重复狭长面。分类场来自已确认标签/种子，不是自动语义证明。
4. 薄桥、分叉和真实特征尺度可能小于平滑半径，必须先锁定其面积归属和接口锚点。平滑只能在允许的测地窄带内进行。
5. 保存原三角 ID、逐角重心权重、原面 ID 和所有新增点的来源；检验逐原三角覆盖、方向、共享边一致性和浮点导出后的退化情况。仅比较总面积或包围盒不能证明无丢面、重叠或位移。
6. 给两侧边界保存有序一一映射并冻结。空间位置接近仅可用来产生候选；最终需确认循环顺序、边邻接、方向和所属表层，不能靠 KDTree 距离独自决定配对。

`partition_triangles` 适用于第 2 步已完成，或原面边已经构成目标边界的情况。它不能替代上述三角面内部剪裁。保留原表面的拆件阶段通常不应移动原顶点；补洞阶段需要移动近圈时，应另设位移范围并记录。

## 按洞型选择建面分支

| 洞型与证据 | 建议方法 | 前置条件与停止条件 |
| --- | --- | --- |
| 原件已经闭合 | 保留并验收；不要重复封盖 | 先分辨真实闭合面与重叠的假盖面；零裸边仍不能证明无自交 |
| 小而简单的单环开口 | 局部约束三角剖分，必要时调和深度恢复 | 实际边界投影为简单多边形、无重边/重顶点和过短边；不要对任意凹环使用中心扇形盖 |
| 长条、U 形大洞，可确认两条侧边链和共同端点 | 单调动态规划配对边链，沿几何余法向采样 Hermite 截面，再联成带 | 显式确定端点和链方向；端点只保留一个共享 ID；一对多配对转成有效三角/四边面；拒绝交叉配对与退化截面 |
| 非平面但可找到单值投影的开口 | 约束 Delaunay 参数网格 + 调和基底 + 受控 Poisson/圆冠凸起 | 在真实边界上验证投影无自交；正参数面积不保证 3D 无折叠；凸起方向与深度来自任务语义和附近几何 |
| 需要规则四边网格的圆盘开口 | 边界到矩形/多块参数域，调和内点布置，再控制凸起 | 需要可解释的角点/边段分配、边界采样兼容和无折叠映射；环长不是四的倍数时不能简单复制端点凑数 |
| 非简单环、分叉、多个独立面扇、洞与窄缝相连 | 先最小拓扑修复或在允许窄带内重切，再重新分类洞型 | 标明保留、移动、删除、重分配的原面；修复超出范围就停止该件并保留进度 |
| 多环、带内岛、隧道或找不到合法单值投影 | 多边界约束参数化、多块面或专门网格方法 | 明确预期拓扑；单圆盘算法不适用，不能把所有环分别盖死来掩盖拓扑差异 |
| 两件需要完全互补的封口 | 一个补面只求解一次，按精确索引复制并反绕序 | 两侧共享同一几何接口；单独生成两个“相近”凸/凹面不保证一致。零间隙不等同打印装配间隙 |

Hermite 的端点导数应来自真实几何面绕序与切向，不应来自平滑着色法线。截面初值相切不证明最终离散曲面严格 C1/G2，更不证明无自交。沿单个轴的 Fourier 轮廓重切只适用于已验证的单值轮廓；绕轴多层或回折表面不能直接套用。

## 先形成合理曲面，再有限优化接缝

第一版补片应考虑两侧切向、曲面走向、周围空间和局部网格密度。把极端折角保留到最后依靠多轮全局平滑，通常会增加返修并扩散位移。

可用面积质量加权的 Laplacian/双调和目标联合优化补片与允许的原面近圈，外圈坐标严格固定，位置约束随测地距离增强。权重只是软约束，不能替代最大位移限制。每轮应检查实际位移、三角翻折和碰撞，再接受候选；越界则回滚或缩小步长。不要通过加大平滑范围自动突破用户要求。

每个接口记录真实三角接缝角的中位数、95 分位与最大值，单独记录面内三角折角。目标阈值依尺度、造型和用途设定，不照搬某件模型的 45°、带宽或权重。切线在曲面上的内禀转角与相邻曲面的二面角用途不同，不能混成一个“平滑度”数字。

同时检查所有接缝与三类交会点、薄桥、角点和补面末端，避免每轮只看一个最坏点。普通失败最多首次加一次针对性改进；若证据表明原边界/拓扑不适用，应换方法而非持续修改平滑系数。缓存每个可回退的候选，保存失败证据和拒绝原因。

## 尺度与数值精度

不要把历史模型中的 `0.6` 带宽、`1e-6` 距离或 `0.012` 面积作为跨模型常量。任务清单应记录物理单位、局部中位边长、接口直径、整体范围以及长度/面积/角度阈值各自单位。

附带函数只使用长度容差 `max(absolute_tolerance, relative_tolerance * 输入包围盒对角线)`，以三角最小高度检测退化；默认相对容差为 `1e-12`。这适合基础防错，不是制造精度声明。空间范围悬殊的模型可按明确部件范围检测，但不能未经记录放宽阈值让坏面通过。

复杂计算宜在靠近原点的局部坐标中使用 float64，并保留可逆变换。还须在实际导出的 float32/文本精度和世界坐标下复测；大坐标上新增点可能量化合并。长度阈值不能直接用于二维叉积/面积比较，应根据量纲转换。对精度无法区分的候选应报告不确定或拒绝，不能解释为已证明无交叉。

## 必须完成的独立几何验收

基础拓扑检查：有限坐标、有效索引、重复面、零/近零面积、裸边、非流形边、内边绕序、断开的顶点面扇、悬空顶点、预期连通块与预期拓扑。Euler 特征可作交叉检查；不能要求所有合法物体都是球面。仅对闭合、方向一致的预期实体解释有符号体积，计算时移近原点减小抵消。

相交验收必须使用实际输出/渲染三角，执行保守候选生成和三角窄相求交，覆盖：补片内部、改动原面内部、补片与改动原面、改动组与未动原面，以及最终整件。检查装配时另外检查部件间相交，将清单中允许共用的接口面单独识别。

共享顶点或共享边的三角对不能整对跳过。只允许交集严格局限于其合法共享点/边；共享一点但别处相交、共面重叠、重复面和面内反折必须被识别。若后端 BVH 候选不包含共享索引邻接对，显式枚举这些对。对于共享点的窄相，应以该真实点为锚，避免病态平面求交偏移。浮点窄相的“精确三角测试”不等同任意精度谓词，报告必须写出容差和能力限制。

局部验收只覆盖变动组时，不能把它报告为整件零自交。原有缺陷需要按来源与空间位置区分；只比较修改前后总数无法判断是否新增。若原缺陷不能在授权范围内修复，记录实际剩余缺陷，不静默放行。

导出后使用独立读取路径重开，核对全部清单部件、实际顶点/面、来源、接缝/配对坐标与反绕序、属性、拓扑和几何指标；核对原文件哈希未变化。验收结果应写明哪些检查执行了、哪些跳过了以及原因。附带函数的 `self_intersection_tested: false` 不允许由封装层改写成通过。

## 提前固定过程图案例与版式

在全量执行前，从真实任务中选择有差异的代表案例，例如长条 Hermite 带、简单投影盖和互补配对面。某类不存在就不虚构案例。每个案例先固定说明目标、6 个左右实际阶段、相机方向/中心/正交尺度、每卡图片比例、字号范围、配色和局部特写位置。

通常记录：原始洞边 → 边界整理/预切 → 参数曲线或初网格 → 未优化补片 → 联合优化 → 实际最终表面。首轮运行即保存各阶段网格快照和数值参数，并将步骤 ID、快照哈希、相机、输出图片、图例和解释写进过程清单。主流程图保持同视角，附加特写单独标注。

预览用低分辨率验证构图、中文字体、文字溢出和图例后，再统一重渲最终图。线框是实际边或注明抽样的实际边；光滑着色不应冒充几何优化。原网格、新补片、可动近圈、裁除窄带必须有准确图例。缺失的中间态若后来重建，应写明重建而非原始记录，并验证复现；不能用相似图补充不存在的过程证据。

## Windows/macOS 部署与历史经验

基础库和其小型测试仅需 Python 标准库，计算不依赖 GPU。Blender 用于真实网格导入/导出、三角化与渲染时，应探测用户指定可执行文件、PATH 和常见安装位置，记录真实版本及需要的 API 能力；不根据设备名称猜测可用后端。外部数值包如 SciPy、约束三角剖分库应安装在本任务隔离环境内，先做小型能力自检，再运行大模型。

CPU/设备配置只影响线程、块大小、预览分辨率和渲染后端，不应使拓扑或几何验收自动变少。记忆体不足时缩小块并保存检查点；如完整验收未完成，应明确保持未验收状态。渲染结果可因设备变化，几何验收仍使用一致的源网格、坐标与容差。

避免从旧流程直接复制以下假设：

- 固定用户绝对路径、对象数字编号、顶点 ID、左右轴解释、GPU 设备和 Windows 中文字体路径。改为清单/命令参数、相对包路径与字体能力探测。
- 将 `core.cp312-win_amd64.pyd` 一类历史二进制 vendor 随包复制；它不能作为 macOS 或其他 Python ABI 的通用依赖。
- 通过解析旧脚本 AST 再 `exec` 抽出函数，或导入时立刻读取大型源文件。可复用原语应是普通模块、无导入副作用，不依赖历史目录存在。
- 使用 `allow_pickle=True` 加载外部 NPZ。通用数据交换应采用数值数组与独立 JSON 元数据；来源未知的可执行对象不属于网格数据。
- 以平滑后的二维代理边界选网格，再原样放回未经验证的三维洞边。二维无交叉只验证了代理域，恢复真实边界时仍可能出现三角倒置和折角。
- 默认所有带孔部分都可投影、所有轮廓都能写成固定轴高度函数、所有四边形内部都平顺，或只检查新补片。每个假设都需要输入证据。

版本化中间结果与来源映射是主要回退手段。失败时恢复上一个已验收候选，保留原始输入和完整日志；不要通过覆盖原件、删除小片、扩大修改范围或降低验收标准获得表面上的“成功”。
